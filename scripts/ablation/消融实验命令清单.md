# CoReM-AD 消融实验命令清单

本文档整理当前仓库中最常用的消融实验命令，默认遵循当前论文口径：

- 点级主消融：`SMD`、`SWaT`
- `TEP`：独立序列级机制验证
- 主报告分数：`cdf_mean`

## 1. 运行前建议

建议先确认以下目录存在：

- 点级数据：`./dataset/anomaly_detect`
- `TEP` 数据：`./TEP-DATA/TEP_Selected_Data`

默认实验产物输出到：

```bash
./artifacts
```

## 2. 点级主消融

### 2.1 A1 表征主干消融

运行 `SMD`：

```bash
bash scripts/ablation/run_full_ablation.sh SMD
bash scripts/ablation/run_a1_wo_decomposition.sh SMD
bash scripts/ablation/run_a1_wo_state_aware_representation.sh SMD
```

运行 `SWaT`：

```bash
bash scripts/ablation/run_full_ablation.sh SWAT
bash scripts/ablation/run_a1_wo_decomposition.sh SWAT
bash scripts/ablation/run_a1_wo_state_aware_representation.sh SWAT
```

一次性跑 `SMD + SWaT` 的 A1 矩阵：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_a1_matrix.sh
```

### 2.2 A2 检索机制消融

运行 `SMD`：

```bash
bash scripts/ablation/run_a2_global_retrieval.sh SMD
bash scripts/ablation/run_a2_state_only_retrieval.sh SMD
bash scripts/ablation/run_a2_context_only_retrieval.sh SMD
bash scripts/ablation/run_a2_dual_condition_retrieval.sh SMD
```

运行 `SWaT`：

```bash
bash scripts/ablation/run_a2_global_retrieval.sh SWAT
bash scripts/ablation/run_a2_state_only_retrieval.sh SWAT
bash scripts/ablation/run_a2_context_only_retrieval.sh SWAT
bash scripts/ablation/run_a2_dual_condition_retrieval.sh SWAT
```

一次性跑 `SMD + SWaT` 的 A2 矩阵：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_a2_matrix.sh
```

### 2.3 A3 融合策略消融

当前论文中固定比较以下融合家族：

- `raw_max`
- `zscore_mean`
- `cdf_max`
- `cdf_mean`
- `cdf_softmax`

其中脚本直接提供的融合消融命令为：

运行 `SMD`：

```bash
bash scripts/ablation/run_a3_raw_max.sh SMD
bash scripts/ablation/run_a3_zscore_mean.sh SMD
bash scripts/ablation/run_a3_pit_fusion.sh SMD
```

运行 `SWaT`：

```bash
bash scripts/ablation/run_a3_raw_max.sh SWAT
bash scripts/ablation/run_a3_zscore_mean.sh SWAT
bash scripts/ablation/run_a3_pit_fusion.sh SWAT
```

一次性跑 `SMD + SWaT` 的 A3 矩阵：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_a3_matrix.sh
```

说明：

- `run_a3_pit_fusion.sh` 当前默认使用 `cdf_mean`
- `cdf_max`、`cdf_mean`、`cdf_softmax` 的比较结果会在测试阶段统一写入 `test_metrics.json`
- 论文 A3 融合策略表建议通过汇总脚本统一生成，而不是手工拼表

### 2.4 A4 时间尺度消融

运行 `SMD`：

```bash
bash scripts/ablation/run_a4_single_scale_short.sh SMD
bash scripts/ablation/run_a4_single_scale_long.sh SMD
bash scripts/ablation/run_a4_multi_scale.sh SMD
```

运行 `SWaT`：

```bash
bash scripts/ablation/run_a4_single_scale_short.sh SWAT
bash scripts/ablation/run_a4_single_scale_long.sh SWAT
bash scripts/ablation/run_a4_multi_scale.sh SWAT
```

一次性跑 `SMD + SWaT` 的 A4 矩阵：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_a4_matrix.sh
```

## 3. 点级主消融一键运行

如果你要按当前论文主线，一次性跑 `SMD + SWaT` 的正式点级消融：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_ablation_matrix.sh
```

如果只跑实验、不自动汇总：

```bash
DATASETS="SMD SWAT" COLLECT_RESULTS=0 bash scripts/ablation/run_ablation_matrix.sh
```

## 4. TEP 独立序列级机制验证

### 4.1 TEP 单项消融

```bash
bash scripts/ablation/run_full_ablation.sh TEP
bash scripts/ablation/run_a1_wo_decomposition.sh TEP
bash scripts/ablation/run_a1_wo_state_aware_representation.sh TEP

bash scripts/ablation/run_a2_global_retrieval.sh TEP
bash scripts/ablation/run_a2_state_only_retrieval.sh TEP
bash scripts/ablation/run_a2_context_only_retrieval.sh TEP
bash scripts/ablation/run_a2_dual_condition_retrieval.sh TEP

bash scripts/ablation/run_a3_raw_max.sh TEP
bash scripts/ablation/run_a3_zscore_mean.sh TEP
bash scripts/ablation/run_a4_single_scale_short.sh TEP
bash scripts/ablation/run_a4_single_scale_long.sh TEP
bash scripts/ablation/run_a4_multi_scale.sh TEP
```

### 4.2 TEP 按组跑矩阵

```bash
DATASETS="TEP" bash scripts/ablation/run_a1_matrix.sh
DATASETS="TEP" bash scripts/ablation/run_a2_matrix.sh
DATASETS="TEP" bash scripts/ablation/run_a3_matrix.sh
DATASETS="TEP" bash scripts/ablation/run_a4_matrix.sh
```

### 4.3 TEP 完整正式矩阵

```bash
DATASETS="TEP" bash scripts/ablation/run_ablation_matrix.sh
```

说明：

- `TEP` 在测试结束后会自动触发离线机制分析后处理
- 默认会输出 sequence-level 结果、机制指标和机制图

如果你暂时不想跑 `TEP` 后处理：

```bash
DATASETS="TEP" TEP_MECHANISM_POSTPROCESS=0 bash scripts/ablation/run_ablation_matrix.sh
```

如果你希望 `TEP` 的 A4 对比缺目录时不要报错：

```bash
DATASETS="TEP" TEP_A4_COMPARE_STRICT=0 bash scripts/ablation/run_ablation_matrix.sh
```

## 5. 分阶段执行

如果你只想先跑某个阶段，例如先跑 `stage_a`：

```bash
bash scripts/ablation/run_full_ablation.sh SMD stage_a
bash scripts/ablation/run_a2_dual_condition_retrieval.sh SWAT stage_a
bash scripts/ablation/run_a4_multi_scale.sh TEP stage_a
```

如果要在固定目录上续跑：

```bash
RESUME=1 bash scripts/ablation/run_a4_multi_scale.sh TEP stage_a
RESUME=1 bash scripts/ablation/run_a4_multi_scale.sh TEP stage_b
RESUME=1 bash scripts/ablation/run_a4_multi_scale.sh TEP test
```

## 6. 常用汇总命令

### 6.1 通用消融汇总

默认按 `cdf_mean` 生成 Markdown 表格：

```bash
python scripts/ablation/collect_results.py --markdown_metric_keys pr_auc roc_auc best_f1 --markdown_score_key cdf_mean
```

点级主表只看 `SMD + SWaT`：

```bash
python scripts/ablation/collect_results.py ^
  --datasets SMD SWAT ^
  --markdown_metric_keys pr_auc roc_auc best_f1 ^
  --markdown_score_key cdf_mean
```

### 6.2 论文专用汇总表

直接生成当前论文结构下的四类表：

```bash
python scripts/ablation/generate_paper_tables.py
```

输出目录：

```bash
./artifacts/paper_tables
```

主要产物：

- `pointwise_main_ablation.md`
- `a3_fusion_family.md`
- `stability_analysis.md`
- `tep_sequence_results.md`

当前论文专用汇总脚本默认指标为：

- 点级主表：`PR-AUC`、`ROC-AUC`、`F1`
- A3 融合策略表：`PR-AUC`、`ROC-AUC`、`F1`
- 稳定性分析表：基于 `PR-AUC`
- `TEP` 主表：sequence-level `AUPRC`、`AUROC`、`F1`

## 7. 推荐执行顺序

如果你现在按论文主线补实验，推荐顺序如下：

1. 跑 `SMD + SWaT` 的 A1-A4：

```bash
DATASETS="SMD SWAT" bash scripts/ablation/run_ablation_matrix.sh
```

2. 跑 `TEP` 的正式矩阵：

```bash
DATASETS="TEP" bash scripts/ablation/run_ablation_matrix.sh
```

3. 生成论文主表与 `TEP` 独立汇总：

```bash
python scripts/ablation/generate_paper_tables.py
```

## 8. 备注

- 当前正式口径下，默认主报告分数固定为 `cdf_mean`
- `A1` 的 `wo_state_aware_representation` 在论文中应解释为 `w/o state-guided modulation`
- 点级主消融正文只建议使用 `SMD`、`SWaT`
- `TEP` 建议单独写成序列级机制验证节
